# 钱包充值 / 提现 需求说明

> 给 `tools/ai_case_gen.py` 读的需求原文。AI 只看这份需求，不看代码 —— 和人写黑盒用例一样。

## 接口

| 接口 | 方法 | 入参 |
|---|---|---|
| `/wallet/deposit` 充值 | POST | `user` 用户, `amount` 金额（字符串，单位元）, `order_id` 订单号 |
| `/wallet/withdraw` 提现 | POST | 同上 |

返回：HTTP 永远 200，业务结果看 body 的 `responseCode`：成功 200，失败 400。

## 规则

1. 金额单位元，最多两位小数；必须大于 0。
2. 单笔上限 50000.00 元（含）。
3. 金额不是合法数字（字母、NaN、空）一律拒绝。
4. 提现金额不能超过当前余额；余额不足时提现失败，余额不变。
5. 同一个 `order_id` 重复提交，只处理一次，第二次原样返回第一次的结果。
